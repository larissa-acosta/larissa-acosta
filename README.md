# Hi, I'm Larissa 👋

Computer Science student at **PUCPR** (Curitiba, Brazil). I work on machine learning for time series, imbalanced data, data streams and 3D data, and I'm building language-model applications in Portuguese.

I care about evaluation done right: no data leakage, honest baselines, and statistical tests when differences are small.
